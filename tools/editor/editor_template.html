    Nenhuma nota. Use a ferramenta Nota para explicar uma ideia ou uma mecânica nova.

    Como usar

    1. Escolha um elemento à esquerda e pinte com o mouse. O botão direito apaga.
    2. A roda do mouse aproxima e afasta. Segure espaço e arraste para mover o mapa.
    3. A ferramenta Sala faz paredes e chão de uma vez. Um clique cobre a tela inteira.
    4. Para uma mecânica nova, ponha uma Nota em cima e escreva como ela funciona.
    5. Tudo fica guardado neste computador sozinho. Quando terminar, clique em Exportar imagem e Exportar dados e mande os dois arquivos no chat.
